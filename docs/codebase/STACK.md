## Environment and Config

- Checked-in config defaults to mock/offline: `src/app/core/generated-config.ts`.
- AWS build config is generated by `tools/generate-config.mjs` from workflow env vars sourced from backend SSM.
- Required AWS generation env vars include `ROADMAP2U_STAGE`, `ROADMAP2U_REGION`, `ROADMAP2U_USER_POOL_ID`, `ROADMAP2U_USER_POOL_CLIENT_ID`, `ROADMAP2U_API_BASE_URL`, `ROADMAP2U_CONTRACT_HASH`.
- No `.env.example` or `.env.template` is versioned in the repository.
